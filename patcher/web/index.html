First, get these two small patch files. Download them, then select them below along with your three game ROMs. You do not need to apply the patches or install Anvil first.

The original Anvil release is now named 0.1.0-alpha; older instructions called it 1.0.0-alpha. The linked engine file is checksum-verified. Its current online builder and newer Reforged releases are not substitutes.

Which patched games work?

You need Sacred Gold Complete 1.05 and Platinum Reforged 0.1.0-alpha, built from the exact original game revisions listed below. These are the two upstream games, not a save or your current Sacred Gold Reforged ROM.

The original Anvil release has the older Windows/Linux builders. Its “in your browser” link now opens a newer builder: do not use that to make this donor. Reforged 0.2 and 0.3 are not accepted. If you do not already have the two correct games, choose Original games instead; it avoids building them separately.
